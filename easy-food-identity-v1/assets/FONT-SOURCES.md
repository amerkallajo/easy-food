# Font sources

Both families are distributed under the SIL Open Font License 1.1. Full license text is included next to each font.

- Manrope variable, weight axis 200–800: https://github.com/google/fonts/tree/main/ofl/manrope
- Cairo variable: https://github.com/google/fonts/tree/main/ofl/cairo
- Retrieved 2026-11-13 from the official Google Fonts repository.
- Logo letterforms use Manrope weight 800 and are converted to editable SVG outlines; no installed font is needed to display the logos.
- Cairo is supplied for Arabic menu, signage, and brand-guide text; it is not the English logo font.

SVG logos are native vector assets. PNG files are raster exports. Mockups elsewhere in this package are visual concepts and not packaging dielines.
